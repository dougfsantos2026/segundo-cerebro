## Padrões a copiar (síntese)

1. **Hero fotográfico edge-to-edge** com overlay escuro — não mock de fachada construída
2. **Header transparente** sobre a mídia
3. **Brand hero-level** + 1 headline + 1 frase + CTA WhatsApp
4. **Mockup de browser/produto** mostrando o site entregue (não card genérico)
5. **Whitespace generoso**, seções com um job cada
6. **Tipografia expressiva** (serif display + sans corpo)
7. **Foto real** de comércio / rua / ambiente — âncora visual

## O que NÃO copiar

- Logos, textos, depoimentos ou cases dos concorrentes
- Preços ou claims genéricos de “IA”
- Layouts de dashboard / card grid no hero
